# ЛАПКИ — учебный зоомагазин

Автор: Верниченко Иван. Группа: ИВТ-5.

## Запуск
Распакуйте весь архив и откройте dist/index.html. Стили, изображения и JavaScript должны оставаться в своих папках. Установка библиотек и сборка не нужны.

Для стабильного сохранения корзины между страницами предпочтителен HTTP-сервер: при установленном Node.js выполните в папке проекта node preview.cjs и откройте http://127.0.0.1:4182. Остановка — Ctrl+C.

## Состав
- dist/index.html — главная, категории, подборка товаров и промоблок.
- dist/catalog.html — 12 учебных позиций, фильтры, сортировка и страницы каталога.
- dist/single.html — карточка выбранного товара, количество и упаковка.
- dist/cart.html — корзина, количество, удаление, промокод LAPKI10 и доставка.
- dist/checkout.html — контакты, доставка, состав и подтверждение учебного заказа.
- dist/information.html — информация, автор, обработка данных и источники фотографий.
- dist/404.html — вспомогательная страница ошибки.

Структура сохранена по пяти ранее предоставленным PSD: Index, Product, Single Page, Shopping Cart и Checkout. Вёрстка выполнена вручную на HTML5, CSS и JavaScript, без конструктора и UI-фреймворков.

## Функциональность и требования
Семантические header, nav, main, article, section, aside, footer, details, summary, output и dialog. Поля связаны с label, группы — с fieldset и legend.

HTML5-валидация: required, type=email/tel/number, minlength/maxlength, min/max и pattern; CSS-состояния валидности. JavaScript дополнительно проверяет пробелы и количество цифр телефона.

Изображения увеличиваются при наведении. Логотип и кнопка наверх поворачиваются на 360°, иконки возврата и удаления — на 180°. Используются transition, ease и cubic-bezier; поддерживается prefers-reduced-motion.

Работают поиск, фильтры категории/серии/цены, сортировка, пагинация, карточки товаров по id, добавление в корзину, подарочная упаковка аксессуаров (+190 ₽), изменение количества, удаление, скидка 10% по LAPKI10, курьер (+490 ₽), подтверждение и скачивание состава заказа.

Корзина хранится отдельно от других вариантов в localStorage под ключом lapki-cart-v1. Для примера откройте пустую корзину и нажмите «Заполнить примером».

Цены, серии и условия демонстрационные. Фотографии иллюстрируют категории; некоторые используются для разных условных серий. Реальные свойства, наличие и состав товаров не заявляются. Настоящие заказы и платежи не выполняются. Имя, email, телефон и адрес не передаются и не сохраняются; скачиваемый файл содержит только состав и сумму.

Как в предыдущем варианте, не включены письмо и рассылка, отдельная SEO-часть, публикация и Lighthouse-аудит. Базовые title, description, lang, кодировка и viewport сохранены.

## Проверки
Все 7 HTML-файлов прошли Nu HTML Checker без ошибок. Ответы — reports/nu-*.json. Локальные ссылки и синтаксис JavaScript проверены.

Встроенный Chromium: все 6 основных страниц при 320, 768, 1000 и 1280 px без горизонтального переполнения. Автор Верниченко Иван присутствует на каждой странице; старый автор отсутствует. Матрица — reports/responsive.json.

Проверены фильтры, упаковка, добавление, сохранение количества после перезагрузки, промокод, доставка, обязательные поля и подтверждение. Контрольный расчёт: (1290 + 190) × 2 − 296 + 490 = 3154 ₽. В проверенных сценариях ошибок консоли нет. Сводка — reports/checks.json.

Отдельные проверки Edge, Firefox и Safari для этого варианта не выполнялись. Скриншоты главной при 320 и 1280 px находятся в reports.
